喵樱 MeowCraft 2.4.1 更新内容
发布日期：2026-11-21
适用平台：Windows x64（便携版，解压即用）

============================================================
一、修好了
============================================================

1. 皮肤页「走路」「自动旋转」点不动
   3D 预览的拖拽事件绑在了整块舞台上，点按钮时指针被画布抢走，
   按钮的点击永远不触发。

   现在拖拽只绑在画布上，按钮条不再被抢：
   - 待机 / 走路 可以正常切换
   - 自动旋转开关能开能关，选择会被记住
   - 重置视角、滚轮缩放都正常

2. Java 下载完是 0KB，然后一直重复下载
   之前有三个问题叠在一起：
   - 下载层不看 Content-Length，连接中途断掉也会把半截包当成完整包
   - 解压直接往 java/jdk-17 里写，中断就留下半成品目录
   - 扫描到目录以为装好了，其实不能用，于是又下一遍

   现在：
   - 下完先比大小，不够就保留 .part 继续续传，不再把坏包往上抛
   - 先解压到 jdk-17.tmp，成功才整体改名上去
   - 装完必须能跑 java -version 才算成功，否则删掉重来
   - 已经装好的 Java 直接复用，不会每次点启动都重下

3. 安装 Java 报 EPERM: ucrtbase.dll
   Windows 上覆盖 bin 目录里的 dll 经常被拒绝：杀毒软件正在扫描，
   或者上一次装的进程还没退干净。

   现在写文件前先删旧文件，遇到 EPERM / EBUSY 会等一会儿重试；
   还不行就给一句人话提示，不再是整串英文堆在弹窗里。
   旧目录删不掉时会提示「游戏正开着或杀毒软件占用，关掉后再试」。

4. 检查更新一直 fetch failed
   GitHub API 在国内经常连不上。

   现在会依次尝试：
   官方 api.github.com → gh-proxy → ghfast → kkgithub
   全部失败才报错，报错里会写清楚试过几条线路。
   更新包下载也加了同样的加速回退。

============================================================
二、改了
============================================================

5. AI 助手回来了，形象换成鲸鱼娘「小鲸」
   上一版把 AI 助手换成了 AI 生图，理解错了需求 —— 这里改回来：
   - 侧边栏「AI 助手」回到整页聊天
   - 右下角有悬浮球，随时点开小窗聊
   - 原来的 SVG 鲸鱼娘换成 AI 生成的 Q 版鲸鱼娘立绘
   - AI 生图整页删除，不再占着侧边栏

   用法没变：没填 API Key 就走免费通道，填了自己的接口优先走自己的。
   右上角「模型设置」里可以填 DeepSeek / OpenAI 兼容接口。

6. 版本隔离（PCL2 那种）
   以前所有版本的模组、存档、资源包、光影都堆在 .minecraft 根目录，
   装两个整合包会互相打架。

   现在每个版本有自己的目录：
   .minecraft/versions/<版本名>/
       mods/
       resourcepacks/
       shaderpacks/
       saves/
       screenshots/

   - 安装完版本就会把目录建好，点「打开目录」直接能看到
   - 第一次进某个版本时，会把全局 .minecraft 里的
     mods / 存档 / 资源包 / 光影 复制一份过去，原目录不动
   - 只复制一次，之后各玩各的
   - 设置 → 存档与整合包 里有「版本隔离」开关，关掉就回到全局共享

7. 整合包的模组进自己的版本目录
   以前整合包解压出来的模组全丢进 .minecraft/mods，
   装第二个整合包就把第一个的模组搅在一起。

   现在整合包的模组装在 versions/<包名>/mods，
   版本列表里点开就能看到「N 个文件」，启动时也只加载自己那份。

8. 右下角下载任务面板
   按 PCL2 的路子补了几项：
   - 每条任务显示已下载 / 总大小（MB）
   - 实时速度（MB/s 或 KB/s）
   - 剩余时间（秒 / 分钟 / 小时）
   - 每条任务都能单独取消；版本安装的取消会真的断开下载
   - 顶部小圆标仍显示正在跑的任务数

9. 设置里的「更新仓库」删掉了
   仓库地址内置在启动器里，只留「启动器更新 v2.4.1 · 检查更新」一行。
   普通用户不用再关心 owner/repo 怎么填。

============================================================
三、安装方式
============================================================

1. 下载 MeowCraft-2.4.1-win-x64.zip
2. 解压后覆盖旧版本目录
3. data 与 .minecraft 不会被覆盖，账号、存档、模组都在
4. 第一次进某个版本时如果看到「复制 mods…」，是在做版本隔离的初始化，
   只会发生一次

============================================================
四、已知问题
============================================================

- 版本隔离默认开启。如果你习惯所有版本共用一份 mods，
  去设置里关掉即可，关掉后不会动已经复制出来的文件。
- 第一次进版本时复制存档可能要几秒，取决于存档大小；
  复制期间启动按钮会显示「准备版本目录…」。
- AI 助手免费通道高峰期会排队，慢的时候等十几秒很正常；
  失败会自动退回离线回答，不会卡住界面。
- 检查更新走公共加速节点，极端网络下仍可能全部失败，
  失败提示里会写清楚试过哪几条线路。
