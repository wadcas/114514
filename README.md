# 启动器更新
1. 版本下载不再卡死

之前点安装后会停在「准备中… 0%」，关掉弹窗再点安装就报 `已有安装任务在进行`。

- 所有网络请求加了超时、30 秒无数据保护和真正的取消
- 「取消」会直接掐断 socket，不再只是改一个标记
- 安装失败 / 取消会立刻释放安装锁，不再留下僵尸任务
- 三分钟无进度判定为死任务，自动清理

### 2. 商店不再卡在骨架屏

搜索结果为空时（例如在「光影」里搜 `xaero`）会一直停在九个灰色占位块。现在直接显示「没有找到符合条件的模组」和重试按钮。

同时修复：当前版本是整合包时，会拿 `1.20.1-forge-47.3.0` 这类加载器 ID 去搜索，结果永远是 0 条；现在先剥出 `1.20.1` 再搜。

### 3. 整合包能在「版本」里看到

装完会按包名生成版本条目：粉色「整合包」徽章、MC 版本、加载器、文件数，直接点启动即可。

Forge / NeoForge 整合包会尝试自动补装加载器，失败也保留版本条目并说明缺什么。

### 4. 下载进度看得见

右下角新增下载浮窗：版本安装、整合包导入、模组下载、Java 下载、AI 生图统一显示，可展开看百分比、当前文件和失败原因。
